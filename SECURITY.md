# Security

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/hamb1y/credlet/security/advisories/new).
Include the affected version, a minimal reproduction using disposable data,
and the impact you observed. Never include real vault credentials or backups.

Credlet is an early release. Security fixes target the latest release; older
versions do not have a separate maintenance branch. No independent security
audit has been completed. See the component guides for supported behavior and
current limits.

For problems in Vaultwarden, Caddy or official Bitwarden clients, use the
upstream project's security reporting process. The server image digests are
pinned deliberately; updates require a reviewed change and a recovery backup.
